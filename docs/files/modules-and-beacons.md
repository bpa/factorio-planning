# Module And Beacon Prototype Data

No module or beacon prototypes are currently loaded by the project. During implementation, locate their definitions in each configured package's prototype tree rather than assuming one file path; parse the actual prototype types and preserve package override order.

For machines, use `module_slots` and `allowed_effects` to constrain module choices. Read module effects from module prototypes. Recipe-level productivity permission is a stronger eligibility signal than subgroup alone. The planner intentionally excludes quality calculations and quality module effects.

Read beacon slots, allowed effects, range/transmission properties, and module effects from prototypes. The Factorio wiki notes that beacons affect eligible nearby machines, with overlapping effects and non-linear transmission; this makes full layout optimization a separate problem. Start with explicit user-selected presets and clearly qualified estimates.

References: [Beacon](https://wiki.factorio.com/Beacon) and [Module](https://wiki.factorio.com/Module).
